# Aarav & Siya — Cinematic Wedding Invitation

A premium, responsive wedding invitation built from scratch in HTML/CSS/JavaScript.

## What is included

- Cinematic hero with couple photography
- Love-marriage story section
- Royal invitation-style event boards
- Interactive 3D-style route reveal
- Photo gallery with parallax/hover depth
- Family section
- RSVP/WhatsApp hook
- Countdown
- Falling petals and subtle motion
- Mobile responsive layout
- All uploaded photographs included in `assets/`

## Run locally

No build tools are required.

1. Unzip the project.
2. Open `index.html` in a browser.

For the best local experience, use a simple local server:

```bash
python -m http.server 5500
```

Then open:

http://localhost:5500

## Important: edit your real wedding details

Open `script.js` and change:

- `weddingDate`
- `whatsapp`
- event names
- event dates
- venue names
- times
- Google Maps links
- event photos

The event configuration is at the top of `script.js`.

## Design direction

The project intentionally combines:
- royal Indian invitation aesthetics
- cinematic wedding-film pacing
- editorial photography
- physical invitation-board styling
- interactive route reveal

The structure is inspired by the general invitation UX patterns seen in the reference sites, but the visual implementation and interaction design are original.
